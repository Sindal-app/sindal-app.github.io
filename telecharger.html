macOS. Le paquet n'est ni signé ni notarié. Au premier lancement, macOS refusera de l'ouvrir par un double-clic : faites un clic droit sur l'application, puis « Ouvrir », et confirmez. Les lancements suivants sont normaux.

Choisir une version

Toutes les versions publiées restent disponibles. Utile pour revenir en arrière si une version vous pose problème — ou pour installer une version précise sur un poste donné.

    Interrogation de GitHub…

    Sur Windows, installer une version plus ancienne par-dessus une récente n'est pas prévu : désinstallez d'abord Sindal depuis Paramètres → Applications. Vos morceaux enregistrés ne sont pas touchés, ils vivent hors du dossier d'installation. En revanche la désinstallation emporte favoris, langue et journaux, qui partagent le dossier de l'application.

    Configuration

    Ce qu'il vous faut

    WindowsWindows 10 ou 11, 64 bits (x64). Aucun runtime .NET à installer : il est inclus dans le paquet.
    macOSApple Silicon (arm64). Les Mac Intel ne sont pas couverts par le paquet publié.
    Espace disqueEnviron 250 Mo, dont 32 Mo pour la banque de sons incluse.
    ConnexionAucune. L'application fonctionne entièrement hors ligne ; seule la recherche de mise à jour, sur Windows, contacte le réseau.
    Carte sonN'importe laquelle. Aucun synthétiseur MIDI externe n'est nécessaire : la synthèse est logicielle et embarquée.
