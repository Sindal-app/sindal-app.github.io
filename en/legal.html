3. Personal data

In the application

Sindal collects, transmits and stores no personal data. There is no account, no identifier, no telemetry, no analytics. The application runs offline: your settings, your pieces and its technical log stay on your machine, in your user folder, and are never sent anywhere.

One exception, on Windows: the update check queries the server hosting the published versions. That request carries no data about you, beyond what any network access technically exposes (IP address).

On this site

This site is entirely static: no cookies, no trackers, no analytics, no forms. Like any web server, the host may log connection data including the IP address, for technical and security purposes. That processing is GitHub, Inc.'s as host.

The audio players on the home page read files hosted on this same site: no resource, font or script is loaded from a third-party service. Only clicking a download button sends you to GitHub.

For any question about your data, write to yannick045@hotmail.fr.
