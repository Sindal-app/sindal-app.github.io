Pick a version

Every published version stays available. Useful to roll back if a release causes you trouble, or to install a specific version on a given machine.

    Asking GitHub…

    On Windows, installing an older version over a newer one is not supported: uninstall Sindal first, from Settings → Apps. Your saved pieces are untouched, they live outside the installation folder. Uninstalling does remove favourites, language and logs, which share the application folder.

    Requirements

    What you need

    WindowsWindows 10 or 11, 64-bit (x64). No .NET runtime to install: it ships inside the package.
    macOSApple Silicon (arm64). Intel Macs are not covered by the published package.
    Disk spaceAround 250 MB, including 32 MB for the bundled sound bank.
    ConnectionNone. The application runs entirely offline; only the update check, on Windows, reaches the network.
    Sound cardAny. No external MIDI synthesiser is needed: synthesis is software and built in.
